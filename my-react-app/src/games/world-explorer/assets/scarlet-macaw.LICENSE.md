## Changes made for the game (CC BY 4.0 asks that these be stated)

- The flying pose baked into a static model (skeleton and animations removed), scaled to life size, material converted, re-centred; the game moves it round the clearing.
- Baked into plain static geometry (no skeleton, no animation); one colour texture converted to JPEG,
  the other texture maps and the material extensions dropped.

## Credit that must stay visible

The review page (dev-preview/phase-2a/PreviewApp.jsx, "Credits") shows the credit, and so does the
Wildlife Gallery. Any release of World Explorer must show the same credit somewhere a player can
reach (an about or credits screen).
