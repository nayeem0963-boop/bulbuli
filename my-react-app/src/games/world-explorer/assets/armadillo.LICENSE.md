## Changes made for the game (CC BY 4.0 asks that these be stated)

- The original is a 3D scan of 1,000,000 triangles (30 MB). It was merged into one mesh and
  **reduced to about 16,500 triangles**, so it is a simplified version of the scan.
- Turned so that it faces +z, tilted 5 degrees nose-up so that all four feet touch the ground,
  scaled to about 0.93 m long, centred and set with its feet on y = 0.
- The colour texture was reduced to a 1024 x 1024 JPEG and a matte finish set.

The original file was 30.7 MB; this one is 651 KB.
